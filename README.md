⛏️ Minecraft-Themed Hackathon Landing Page

A creative Minecraft-inspired hackathon landing page designed to turn a traditional event website into an immersive block-based experience. The website combines a playful Minecraft aesthetic with a clean, modern UI to showcase the hackathon, its challenges, timeline, and key information.

🌲 Features

* ⛏️ Minecraft-inspired visual design
* 🧱 Block-based UI elements and styling
* 🌄 Immersive hero section
* ⚔️ Hackathon challenges presented as quests
* 📜 Interactive event timeline
* 💎 Engaging animations and transitions
* 🗺️ Clear and minimal one-page layout
* 📱 Responsive design for different screen sizes
* 🎮 Gamified experience inspired by Minecraft

🛠️ Tech Stack

* HTML
* CSS
* JavaScript

🚀 Getting Started

Clone the repository:

git clone https://github.com/yuvrajtrivedi-py/djscsi-hackathon-27.git

Open the project in VS Code and run it using a local development server such as Live Server.

🎯 Concept

Instead of presenting the hackathon as a conventional event website, the landing page treats the event like a Minecraft adventure.

Participants are introduced to the event, discover why they should join, and explore the hackathon journey through a game-inspired interface — making the experience feel less like reading a website and more like entering a new world.
